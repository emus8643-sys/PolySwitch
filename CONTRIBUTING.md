# Contributing

Issues and pull requests are welcome. Include your distribution, KWin/Plasma and Qt versions, Wayland/X11 session type, monitor arrangement, window count, and exact reproduction steps. Please remove window titles, usernames, paths and credentials from logs/screenshots before posting them.

Build against the target KWin version. Run the core tests. Test rendering and input changes in an isolated virtual/nested KWin session rather than restarting the main compositor. Never include personal settings or compiled plugin binaries in a source pull request. Preserve license notices.
